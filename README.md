# QuizLab — Tech Quiz Application

A modern, interactive web-based quiz app to test your skills in **Core Java, Advanced Java, HTML, CSS, JavaScript, Angular, and MySQL**. The app provides immediate feedback, tracks progress, and allows users to review answers.

---

## Features

- Multiple categories: Core Java, Advanced Java, HTML, CSS, JavaScript, Angular, MySQL
- Interactive UI built with **Bootstrap 5**
- Progress bar for tracking quiz completion
- Immediate feedback for correct and incorrect answers
- Score display at the end of the quiz
- Review all answers with correct values
- Ask user name and store scores in **local storage**
- Leaderboard for top scores (stored in browser)

---

## Technologies Used

- **HTML5** & **CSS3**
- **JavaScript (ES6)**
- **Bootstrap 5**
- **LocalStorage** for saving scores and leaderboard
